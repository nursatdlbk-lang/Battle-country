# Sound assets

Place sound effect files here.
Supported formats: MP3, WAV, OGG.

Built-in deterministic WAV cues:
- melee_hit.wav
- projectile_shot.wav
- projectile_impact.wav
- wall_bounce.wav
- ko.wav
- winner.wav

The preview and Remotion export use these files unless a custom sound URL is
configured for the corresponding cue.
